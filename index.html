PureCap — 隐私政策

更新日期：2026 年 9 月 29 日 ｜ 开发者：MingLiu（个人开发者）

一句话概括：PureCap 完全在您的电脑上本地运行，不上传、不收集您的任何数据，没有广告，也没有任何第三方组件。

1. 我们收集哪些数据

  • 不收集。PureCap 不收集、不存储、不传输任何个人数据、使用统计或遥测数据。
  • 您录制的视频（画面与声音）只写入您自己电脑的"视频"文件夹，开发者无法访问。

2. 屏幕与麦克风

  • 屏幕画面：仅在您明确选择录制目标（整个屏幕或某个应用窗口）并点击"开始录制"后，才通过 Windows 系统自带的屏幕捕获能力（Windows.Graphics.Capture）读取屏幕内容，且只用于写入您本地的视频文件。
  • 系统声音：仅当您勾选"录制系统声音"时，通过 Windows 音频接口（WASAPI）采集电脑正在播放的声音，写入本地视频文件。
  • 麦克风：仅当您勾选"录制麦克风"时采集麦克风声音，写入本地视频文件；未勾选时麦克风不会被启用。
  • 录制内容不在任何服务器上暂存、分析或转发。

3. 网络访问

  • PureCap 的录屏功能完全离线运行，不需要网络，程序内没有任何联网代码、统计 SDK 或广告组件。
  • 仅 Microsoft Store 自身（下载、更新、授权）会按微软的隐私政策与系统通信，PureCap 不参与、不接触其中数据。

4. 第三方组件

无。PureCap 仅使用 Windows 操作系统自带组件（Windows.Graphics.Capture、Media Foundation、WASAPI、Direct3D 11），不包含任何第三方开源或闭源组件。

5. 儿童隐私

本软件不面向儿童，也不收集任何年龄数据。

7. 政策变更

如本政策发生实质性变更，将在本页面更新并修改顶部日期。

Screen, system audio, and microphone are captured only when you explicitly start a recording, and are written only to local video files. No third-party components, no ads.
